# Amber Cup - Coffee Shop Landing Page (Task 1)

A modern, responsive landing page for a specialty coffee shop built using **HTML5**, **Tailwind CSS**, and **Vite**.

## 🚀 Live Demo
- **Live Deployment:** [Amber Cup Live Site](https://coffee-shop-task1.vercel.app/)

## 📱 Features
- **Hero & Navigation Header:** Clean navigation bar with branded action buttons.
- **Featured Menu & Product Showcase:** Grid layout highlighting top coffee blends and pastries.
- **Interactive Call to Action:** Prominent shop buttons for easy online ordering.
- **Fully Responsive Design:** Optimized for mobile, tablet, and desktop viewports using modern Tailwind utilities.

## 🛠️ Tech Stack
- **HTML5**
- **Tailwind CSS (v4)**
- **Vite**
