# SaaS Flexible Pricing Plans (Task 2)

An interactive, responsive SaaS pricing section created using **HTML5**, **Tailwind CSS**, and **Vite**.

## 🚀 Live Demo
- **Live Deployment:** [SaaS Pricing Live Site](https://frontend-development-internship-202-zeta.vercel.app/)

## 🎨 Features & Highlights
- **3-Tier Pricing Structure:** Clear breakdown for Starter, Pro, and Enterprise tiers.
- **Visual Hierarchy:** Featured "Most Popular" card with custom gradient badges and glow accents.
- **Dark Theme Palette:** Styled with rich indigo/violet gradients, frosted glass card containers, and balanced outline buttons.
- **Interactive Hover States:** Smooth hover translation and shadow glow effects for enhanced user experience.
- **Responsive Layout:** Responsive CSS Grid that scales dynamically from single-column mobile view to 3-column desktop view.

## 🛠️ Tech Stack
- **HTML5**
- **Tailwind CSS (v4)**
- **Vite**
